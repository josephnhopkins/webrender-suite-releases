# Webrender Suite — releases

Downloads for **Webrender Suite**, one small download that installs the Webrender programs for
Windows — Pdf Desk, Markdown Editor, Text, Sticky Notes, Lists and Library Desk — with
**Webrender**, the purple W that starts them, from Nextwaveweb Ltd. It holds none of the programs
itself: it downloads each one's own installer from that program's GitHub Release, checks it, and
runs it. Each program installs as itself, and each is removed on its own in Settings → Apps.

This repository holds no source code — only the released builds: one GitHub Release per version,
with the download as its asset. A new version is cut when one of the programs it installs has a
new release.

Windows is at 0.1.0.
