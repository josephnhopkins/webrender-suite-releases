# Webrender Suite — releases

Downloads for **Webrender Suite**, from Nextwaveweb Ltd: a Windows app that installs the Webrender apps and updates them. It
installs for you alone, in your own user folder, with no administrator rights. The first time it opens it offers every Webrender
app, each one ticked; untick any you do not want. Each app is downloaded from its own GitHub Release and checked against
Webrender's release feed before it runs, and each installs as itself, so Settings → Apps lists and removes each one on its own.
After that, Webrender Suite shows each app's installed and newest version, with an Update when there is one. Removing it removes
no other app.

This repository holds no source code — only the released builds: one GitHub Release per version, with the download as its asset.
Versions 0.1.0 and 0.1.1 were a different download, which installed six apps at the versions it was built with.

Windows is at 0.2.0.
